# 🍔 Food Delivery System

Food Delivery App using Java, Spring Boot, Hibernate, MySQL.
Order Food, Manage Restaurants, Track Orders.

## ✨ Features
- Browse Restaurants & Food Menu
- Add Food to Cart & Place Order
- Manage Restaurants, Food Items
- Order Tracking & Status Update
- User Friendly Web UI with Thymeleaf

## 🛠️ Tech Stack
- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Thymeleaf, HTML, CSS
- Maven

## 🚀 How To Run
1. Create Database in MySQL: `food_delivery_db`
2. Update `src/main/resources/application.properties` with your MySQL username/password
3. Run `FoodDeliveryApplication.java` in Eclipse
4. Open Browser: `http://localhost:8080`

## 📁 Project Structure
- `controller` - Web Controllers
- `service` - Business Logic
- `repository` - Database Access
- `entity` - Database Tables
